# 🌍 International Youth Goals (PWA)

> Platform berbasis web modern yang dirancang untuk mendukung kolaborasi, pemberdayaan, dan pencapaian tujuan pembangunan berkelanjutan bagi generasi muda global.

## 🚀 Tentang Proyek
**International Youth Goals** adalah aplikasi *Progressive Web App* (PWA) yang dibangun untuk memberikan pengalaman selayaknya aplikasi native yang cepat, ringan, dan dapat diakses secara *offline*. Proyek ini berfokus pada inisiatif kepemudaan, edukasi, dan aksi kolaboratif lintas batas dalam rangka mendorong keterlibatan aktif anak muda di kancah internasional.

---

## ✨ Fitur Utama (PWA Features)
- ⚡ **Performa Cepat & Responsif:** Dioptimalkan untuk berbagai ukuran layar, mulai dari perangkat mobile hingga desktop.
- 📶 **Dukungan Offline (*Offline-First*):** Dilengkapi dengan *Service Worker* sehingga aplikasi tetap dapat diakses meskipun koneksi internet tidak stabil.
- 📲 **Dapat Diinstal (*Installable*):** Pengguna dapat langsung memasang aplikasi ini ke layar utama (*home screen*) perangkat seluler atau komputer tanpa melalui toko aplikasi pihak ketiga.
- 🔔 **Notifikasi & Akses Instan:** Memberikan pengalaman interaktif yang mulus bagi pengguna dalam memantau program dan kegiatan terbaru.

---

## 🛠️ Tech Stack
Proyek ini dikembangkan menggunakan teknologi web modern, di antaranya:
* **Frontend Framework:** (Contoh: Vue.js / React / Next.js)
* **PWA Integration:** `vite-plugin-pwa` / Workbox
* **Styling:** Tailwind CSS
* **Database / Storage:** IndexedDB / Firebase
